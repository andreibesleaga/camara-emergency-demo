Self-hosted webfonts (latin + latin-ext variable subsets) so the demo needs no font CDN at runtime
and stays within the production Content-Security-Policy (font-src 'self').

- Outfit (display) — SIL Open Font License 1.1, see OFL-Outfit.txt
- Nunito Sans (body) — SIL Open Font License 1.1, see OFL-Nunito-Sans.txt

Source: Google Fonts (fonts.gstatic.com), variable weight axis 400-700.
